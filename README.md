# PitchLab Pro — Cloud Deployment Package

This bundle contains your complete, self-contained **PitchLab Pro (11v11 & 7-a-Side Football Tactics, Squad Management & 60 FPS Match Simulator)** web application (`index.html`), pre-configured for instant static cloud hosting.

## Option 1: Instant Drag-and-Drop (Netlify Drop — No CLI Needed)
1. Open https://app.netlify.com/drop in your browser.
2. Drag and drop `pitchlab-pro-deploy.zip` (or the unzipped folder) directly onto the page.
3. Your live HTTPS URL is generated immediately.

## Option 2: Vercel (CLI or GitHub)
1. Install Vercel CLI (`npm i -g vercel`) or push this folder to a GitHub repository.
2. Run `vercel --prod` inside this directory (`vercel.json` is pre-configured).

## Option 3: GitHub Pages / Cloudflare Pages / Firebase Hosting
1. Upload `index.html` to a GitHub repository or static bucket.
2. Enable GitHub Pages or Cloudflare Pages on the root directory.
